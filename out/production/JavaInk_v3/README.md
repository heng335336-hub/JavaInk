## 📝 Featured Project

### JavaInk — Smart Notepad Redesign
<img src="https://github.com/heng335336-hub/JavaInk/blob/main/pngs/javaink.png?raw=true" alt="JavaInk" width="50" height="50">

A modern desktop text editor inspired by Notepad, but improved with better structure, usability, and future expansion features.

**JavaInk aims to:**
- Provide a cleaner and more powerful writing experience
- Improve usability compared to classic Notepad
- Serve as a foundation for advanced text tools in Java
